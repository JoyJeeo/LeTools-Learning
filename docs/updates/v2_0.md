# LeTools-Learning 更新日志

**2026-09-20**

## Key Features

### 1. 新增模型

- 新增 **Xiaomi-Robotics-0 / Xiaomi-Robotics-1** 
- 新增 **Galaxea G0.5** 
- 新增 **Wall-X-0.5** 


### 2. SG100 灵巧手末端

- 数据转换、在线推理、bag 回放和离线评测全链路支持 SG100。
- 支持每手 **1 维开合量**至 **11 维全关节**。
- 内置兼容驱动端的 ROS 消息定义，支持位置与关节阻抗指令。
- 外部模型 adapter 统一通过 `eef_dof` 配置末端维度。


### 3. Kuavo 5W 全身控制

- 新增 5W 底盘移动模式，在双臂和末端动作之外统一纳入 **3 维底盘移动**。
- 新增 5W 全身模式，在双臂和末端动作之外统一纳入 **4 维下半身关节**。
- 支持推理时下半身任意关节锁定(采用go_bag_path中的值)
- 动作与观测维度改为由平台、单/双臂、末端类型动态计算。

### 4. 全身 VLA 案例

新增 **Roban wholebody VLA** 端到端参考实现，覆盖：

- Roban Rosbag 到 LeRobot 数据集的转换和 23 维状态 / 32 维动作定义。
- OpenPI、Isaac GR00T N1.7 和 LingBot-VLA v2 全身训练与推理 adapter。
- 基于 CycloneDDS 与 HEFT 的推理pipeline。


### 5. 数据与部署改进

- 新增并行数据转换功能，可同时处理多个数据源，提高转换效率。
- 新增 H.265 Rosbag 解码与 LeRobot v3 转换支持，降低长时间采集的存储压力。
- 支持相机频率与训练频率不能整除时的时间戳重采样。
- 帧对齐使用当前或历史观测，避免将未来帧泄漏到当前控制步。
